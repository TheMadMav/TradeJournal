# TradeJournal

Kostenloses Trading-Journal für MetaTrader 5 mit Prop-Firm-Tracker. Läuft lokal auf deinem Windows-PC, deine Daten bleiben bei dir.

- **Download:** [neueste Version](https://github.com/TheMadMav/TradeJournal/releases/latest)

## Installation
1. `TradeJournal-x.y.z.zip` herunterladen und mit „Alle extrahieren“ entpacken.
2. Doppelklick auf „TradeJournal“. Beim ersten Start fragt Windows einmal nach.
3. Die Checkliste unter „Hilfe & Anleitung“ führt durch Konto, MT5-Dienst und Zeitzone.

Updates findet das Journal selbst. Dabei wird nur gelesen, welche Version aktuell ist.

TradeJournal ist ein Werkzeug zur Dokumentation und Auswertung, keine Anlageberatung. Nicht verbunden mit MetaQuotes oder einer Prop-Firm.
